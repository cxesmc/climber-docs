# climber-docs (deprecated)

The CLIMBER-X documentation now lives in the main code repository and is built
and published with [Quarto](https://quarto.org):

**https://cxesmc.github.io/climber-x/** — source: [`cxesmc/climber-x`](https://github.com/cxesmc/climber-x) under `docs/`.

This repository is no longer the source of the documentation. Its `gh-pages`
site simply redirects to the new location.

The previous mkdocs-based site and its source are preserved on the
[`archive`](https://github.com/cxesmc/climber-docs/tree/archive) branch.
